Detailed Description

Persisted application configuration, backed by QSettings.

Note
Thread-safety: Thread-safe.

Settings is a process-wide singleton (see instance()). On construction, any setting missing from the backing store, or holding a value outside its documented invariant, is reset to its default (see settings.cpp).
