Detailed Description

Forwards Qt's critical and fatal log messages to Better Stack Logs.

The destination (ingesting host + source token) is compiled in from the BETTERSTACK_SOURCE_TOKEN/BETTERSTACK_INGESTING_HOST CMake cache variables (see betterstackconfig.hpp.in) - there is no runtime setting and nothing for a user to configure. If either is unset at build time, install() is a no-op and the app behaves exactly as it did before this class existed.

Never instantiated: every member is static.
