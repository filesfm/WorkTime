QUrl Utilities::extractResourceToDisk ( const QString & sourcePath,
const QString & fileName )
static

Copies a file (e.g. a :/ Qt resource) to a fixed path under the system temp directory, overwriting any file already there.

Needed because some platform APIs (e.g. Qt.labs.platform's SystemTrayIcon on Linux) can't load an icon straight out of the Qt resource system and need a plain file:// path instead.

Parameters
sourcePathPath to copy from, as accepted by QFile (a :/... resource path or a path on disk).
fileNameDestination file name, placed directly under QStandardPaths::TempLocation.
Returns
A file:// URL pointing at the destination path.
Cyclomatic complexity: 1

◆ truncateUtf8Safe()

QString Utilities::truncateUtf8Safe ( const QString & value,
qsizetype maxCodePoints )
static

Truncates value to at most maxCodePoints Unicode code points.

Truncation happens at a code-point boundary rather than a UTF-16 code unit boundary, so a surrogate pair (a character outside the Basic Multilingual Plane, e.g. an emoji) is never split - which in turn guarantees the UTF-8 encoding of the result is never split either.

Returns
value unchanged if it already has at most maxCodePoints code points, otherwise the first maxCodePoints of them.
Cyclomatic complexity: 2
