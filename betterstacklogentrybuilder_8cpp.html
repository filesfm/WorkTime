Builds one Better Stack Logs HTTP-source event body for a single critical/fatal Qt log message.

type must be QtCriticalMsg or QtFatalMsg - it is encoded as the "fatal" or "critical" level field, nothing else. category is the originating QMessageLogContext::category (e.g. "worktime.settings"), or empty/"default" for uncategorized messages, in which case the "source" field is omitted. appVersion is the app's version string (e.g. "0.6.0"), always included as the "app_version" field.

Shared by BetterStackLogger (live messages) so the wire format stays in one place and is unit-testable independently of installing a global Qt message handler.
